# Quizzy 🎯

Quizzy is a modern full-stack online quiz and assessment platform built using **Flask**, **PostgreSQL (Supabase)**, and deployed on **Render**.

It allows teachers and creators to build interactive quizzes with multiple question types, evaluate responses automatically or manually, and share quizzes using simple public links.

---

# ✨ Features

## 📝 Multiple Quiz Modes
- Multiple Choice Questions (MCQs)
- Match the Column
- Written / Descriptive Answers

---

## ⚡ Smart Evaluation
- Automatic grading for objective questions
- Manual checking for written answers
- Instant score calculation

---

Create quizzes directly from:

# 🚀 Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/quizzy.git
cd quizzy
```

---

## 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Setup Environment Variable

Create a `.env` file or set:

```env
DATABASE_URL=your_postgresql_connection_string
```

---

## 4️⃣ Run the Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
